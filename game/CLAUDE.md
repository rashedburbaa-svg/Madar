# قواعد مشروع لعبة مستعمرة المدار (Orbit Colony)

## هوية اللعبة ونمطها
- **الاسم:** مستعمرة المدار (Orbit Colony)
- **النوع:** محاكاة بقاء وبناء مستعمرات فضائية + دفاع أبراج + معارك زعماء + استكشاف مجرة (الفصل الثاني).
- **الأسلوب البصري:** 3D Pixar-style، ألوان أساسية أبيض وذهبي مع إضاءة سماوية (Cyan).
- **الموارد الأساسية:** المعادن، الطاقة، الغذاء، الكريستال.

## قواعد هندسية صارمة عند التعديل
1. **عدم كسر التوافق (Backward Compatibility):** لا تغيّر أسماء مفاتيح الحفظ (Save Keys) أو بنية بيانات المباني والموارد بدون كتابة دالة ترحيل (Migration) آمنة.
2. **فصل البيانات عن المنطق:** جداول الأسعار، السعة، ونقاط صحة الأعداء تُحفظ في ملفات إعدادات/بيانات منفصلة عن منطق اللعب.
3. **الأداء (60 FPS):** استخدم Object Pooling للوحوش، المقذوفات، والمؤثرات البصرية المتكررة.
4. **التنفيذ المرحلي:** قبل كتابة كود لأي ميزة كبيرة (مثل خريطة المجرة)، اعرض خطة التنفيذ وقسّمها إلى خطوات صغيرة قابلة للاختبار.
